# Warm-start QAOA drug-response benchmark

Code and archived results for the IonQ Forte-1 study: 25 executions, 5,300 shots, 18 circuits and 14 optimization instances.

| Task | Guide |
|---|---|
| Rebuild tables and figures or rerun analyses | [Reproduction](docs/reproduction.md) |
| Find Tables S1–S11 and Figures S1–S3 | [Supplementary material](docs/supplementary.md) |
| Obtain original DREAM measurements | [Source data access](docs/data-access.md) |

## Files

| Location | Contents |
|---|---|
| [reproduction/](reproduction/) | Runnable scripts, checks and pinned requirements |
| [reproduction/evidence/](reproduction/evidence/) | Archived hardware records, coefficients and frozen designs |
| [reproduction/analysis/](reproduction/analysis/) | Saved numerical results and execution records |
| [reproduction/overleaf/](reproduction/overleaf/) | Manuscript, supplementary sources and figures |
| [SHA256SUMS.json](SHA256SUMS.json) | File integrity manifest |

All runnable files retain their internal paths under `reproduction/`. Cite a versioned [release](https://github.com/itsShrizon/warm-start-qaoa-drug-response-reproducibility/releases) using [CITATION.cff](CITATION.cff). The original snapshot remains available as `v1.0.0`.
